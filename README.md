# 🚀 ASP.NET Core MVC

A practice project covering essential ASP.NET Core MVC concepts, with multiple implementations organized within a single application. The project focuses on understanding MVC architecture, passing data between controllers and views, handling forms, and working with models.

## 🛠️ Technologies Used

* C#
* ASP.NET Core MVC
* Razor Views
* HTML and Tag Helpers
* Data Annotations
* .NET

## 📚 Concepts Practiced

### Views and Data Passing

* Razor Views and Razor syntax
* ViewData, ViewBag, and TempData
* Strongly Typed Views
* Passing Multiple Models to a View

### HTML Helpers and Tag Helpers

* HTML Helpers
* Strongly Typed HTML Helpers
* Tag Helpers for forms and HTML elements

### Models and Validation

* Model Data Types
* Data Annotations
* Model Validation

### Form Handling and HTTP Methods

* Handling Multiple Buttons in a Single Form
* Form Submission and Controller Actions
* HTTP Methods such as GET and POST
* Handling Form Data in Controller Actions

## 📁 Project Structure

The application follows the standard ASP.NET Core MVC folder structure.

```text
ASP.NET-Core-MVC/
├── Controllers/
├── Models/
├── Views/
├── _ViewStart.cshtml
├── _ViewImports.cshtml
├── _Layout.cshtml
└── README.md
```

*Note: The structure above is illustrative. The actual project may contain additional files and folders.*

## 🎯 Learning Objectives

* Understand the Model-View-Controller architecture.
* Pass data between controllers and views using different techniques.
* Work with Razor syntax, HTML Helpers, and Tag Helpers.
* Apply model validation using Data Annotations.
* Handle multiple models and form submissions.
* Understand HTTP methods and controller action handling.

## 🚀 Purpose

This repository serves as a reference for ASP.NET Core MVC concepts practiced through a single application, with implementations organized for learning and future reference.
